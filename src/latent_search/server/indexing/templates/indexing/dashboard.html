🔄 Cross-Machine Caption Workflow

Use this to offload caption generation (VLM) to a GPU-enabled machine. Both machines need access to the same photo files.

  1. On your main (CPU) machine:
    Click Export. Choose "Uncaptioned only" for smaller transfers.
    Download an .ndjson file with your library metadata.
  2. Transfer the file to your GPU box:
    Copy it via USB, SCP, or any method you prefer:
    scp latent_export*.ndjson user@gpu-box:/tmp/
  3. On the GPU machine:
    Open Latent Search → click Import → select the exported file.
    Set the media root to match where photos live on this machine.
    Click Captions — GPU acceleration will speed things up dramatically.
  4. After captions are done:
    Click Export again (choose "All" to get everything).
    Transfer the file back to your main machine.
  5. Back on your main machine:
    Click Import → select the returned file.
    Your captions merge into existing records automatically.
Frequently asked questions
Do both machines need the same Qdrant instance?
No. Each server manages its own vector database independently.
Will importing erase my existing data?
No. Records are matched by file path and merged — nothing is deleted.
Can I use this as a backup?
Yes — exporting all records gives you a portable snapshot of your library metadata.
Does this export image files?
No — only metadata (paths, timestamps, captions). Images stay on disk.
